# Changelog

All notable user-visible changes to the Mealie TOS application package.

## 3.28.0-1 — 2026-09-27

### Added
- First release. Mealie (`hkotel/mealie:v3.28.0`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8010 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/mealiedocker/`.
